# Security

Security fixes go into the latest release only.

## Reporting a vulnerability

Report it privately through [GitHub's security advisories](https://github.com/calmerism/Tuned/security/advisories/new), not as a public issue. Include the version, the steps to reproduce it and what an attacker could do with it.

You'll get a reply within a few days. The fix and the details are published together once a patched release is out.
